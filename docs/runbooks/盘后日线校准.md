# 盘后日线校准

## reconcile_daily

目标：保证 `public.kline_daily` 在交易日结束后具备可追溯、可重跑、可回退的校准流程。

- 盘后执行窗口：`reconcile_daily / sync_daily_basic` 当前从 `16:30` 开始，不在 `15:00` 后立刻触发。

- 推荐命令：
  - `python collector/reconcile_daily.py --host 127.0.0.1 --port 5432 --user wt --password '***' --dbname stock_realtime --source tushare`
  - `python collector/reconcile_daily.py --host 127.0.0.1 --port 5432 --user wt --password '***' --dbname stock_realtime --source tushare --trade-date 2026-04-03`
  - `python collector/sync_daily_basic.py --host 127.0.0.1 --port 5432 --user wt --password '***' --dbname stock_realtime --trade-date 2020-01-02`
  - `python collector/sync_daily_basic.py --host 127.0.0.1 --port 5432 --user wt --password '***' --dbname stock_realtime --date-from 2020-01-01 --date-to 2026-04-09`

- 入口：以交易日为边界触发（`reconcile_daily`），默认回补上一交易日，并在必要时可按历史日期重跑。
- 默认日期推导：不再依赖 `trading_calendar`，默认回补“上一工作日”；若节假日需要精确控制，建议显式传 `--trade-date`。
- 当前盘后日线源：默认优先 `tushare`。
- 写入表：`public.kline_daily`，主键 (`instrument_id`, `trade_date`)。
- 当 `--source tushare` 时，会在 `kline_daily` 之外同步 `public.daily_basic`，主键同样为 (`instrument_id`, `trade_date`)。
- 结果入审计：`job_runs` 记录本次执行状态与计数。
- 区间回灌时，`sync_daily_basic.py` 会先通过 `Tushare trade_cal` 过滤开市日，再逐日同步 `daily_basic`。
- 当前系统服务口径：盘后链路会先判定今天是否开市；若开市，显式按“今天的 `trade_date`”执行 `reconcile_daily` 和 `sync_daily_basic`。

## 执行步骤（最小）

1. 校验当日日线是否存在缺口。
2. 当 `--source tushare` 时，先拉取 `pro.daily(trade_date=...)` 写入 `public.kline_daily`，再拉取 `pro.daily_basic(trade_date=...)` 写入 `public.daily_basic`。
3. `daily_basic` 当前最小字段：
   - `turnover_rate`
   - `total_share`
   - `float_share`
   - `free_share`
   - `total_market_cap`
   - `circulating_market_cap`
4. 对失败来源写 `data_quality_log`（通常 `data_domain='daily_reconcile'`）。
5. 在 `job_runs` 写 `status` 为 `success/partial/error` 与 `processed_count`。

## 盘后时序（当前口径）

1. `16:30` 起先判断今天是否为交易日；非交易日整条日线盘后链路跳过
2. 若是交易日，先执行 `reconcile_daily(当日)`
3. 再执行 `sync_daily_basic(当日)`
4. 再执行 `sync_daily_adj_factor(当日)`，同步股票复权因子
5. 再执行 `calculate_daily_indicator(当日)`，股票按前复权 `qfq_close` 计算 MA，指数按原始 `close` 计算 MA
6. 板块目录 / 成分同步已拆到 `20:00` 单独执行
7. 若盘后任务失败，优先重试失败任务，不要回退到盘中链路补救

## 与三事实表边界

- 日线是历史真值层，不允许删历史，不允许重建全库。
- 允许覆盖同一日主键条目（可追溯替换），但不影响其它日期记录。
- 当日来源出现异常时，保留旧值并记录告警，待重试后再补齐。

## daily_basic 单位说明

- `turnover_rate`：百分比
- `total_share`：万股
- `float_share`：万股
- `free_share`：万股
- `total_market_cap`：万元
- `circulating_market_cap`：万元

当前 collector 直接保留 Tushare 原始单位，不在入库阶段换算为“股/元”。

## 常见问题

- `Tushare` 返回缺口或临时错误
  - 表现：`data_quality_log` 中出现 `daily_reconcile/missing_daily`、`missing_daily_basic`、`daily_basic_source_error` 或 `source_error`。
  - 处置：优先重试 `reconcile_daily --source tushare`，必要时再对缺失日期做显式 `--trade-date` 重跑。
- 同一日重复重跑导致量值叠加风险
  - 表现：`volume/amount` 变化异常偏大。
  - 处置：限制重跑窗口、核验 `kline_daily` 同日变动量，必要时做对账。
