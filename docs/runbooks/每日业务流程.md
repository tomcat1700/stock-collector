# 每日业务流程

## 1. 开盘前

### 1.1 交易日判定

- 当前盘中主链路按固定交易窗口运行：
  - `09:29:56-11:30:03`
  - `12:59:58-15:00:03`
- 非交易时段不进入主采集，也不写 heartbeat。

### 1.2 开盘前静默

- `09:29:56` 之前不进入 `realtime_quotes` 主采集。
- 当前未把 `09:15-09:25` 集合竞价过程接入 `realtime_quotes` 主链路。

## 2. 盘中

### 2.1 上午连续采集

- `09:29:56-11:30:03`
- 正常连续采集 `public.realtime_quotes`

### 2.2 午休

- `11:30:04-12:59:57`
- 不采集，不写 `realtime_quotes`

### 2.3 下午连续采集

- `12:59:58-15:00:03`
- 正常连续采集 `public.realtime_quotes`

## 3. 盘中数据处理

### 3.1 实时快照

- 当前主源：`sina`
- 当前 cadence：`2s`
- `sina` 写入必须携带 source-side `trade_date + trade_time`
- `quote_time` 必须与 source-side 时间一致
- 非交易时段不写 heartbeat；交易时段内 heartbeat 当前按 `2s` 节流

### 3.2 去重规则

- 采集指纹：`(instrument_id, trade_date, trade_time)`
- 若相同指纹已存在，则直接丢弃
- 不做 `update`
- 不重复插入

### 3.3 分钟聚合

- `realtime_quotes -> kline_minute(period=1)`
- `period=1 -> 5/15/30/60`
- 当前 `kline_minute` 统一承载 `1/5/15/30/60`

## 4. 盘后

### 4.1 任务起始时间

- `16:30` 开始日线与 `daily_basic`
- `20:00` 开始板块目录与成分股同步

### 4.2 执行顺序

1. 先判断今天是否为交易日；非交易日两段盘后链路都直接跳过
2. `16:30` 执行 `reconcile_daily(当日)`
3. `16:30` 执行 `sync_daily_basic(当日)`
4. `20:00` 执行 `sync_eastmoney_sectors`
5. `20:00` 执行 `sync_eastmoney_sector_stocks`

### 4.3 日线校准

- `reconcile_daily` 负责盘后日 K 线校准
- 当前主用源：`Tushare`
- 当前系统服务口径：显式同步当天 `trade_date`
- 手工重跑时若需要精确指定日期，显式传 `--trade-date`

### 4.3.1 daily_basic 同步

- `sync_daily_basic` 负责盘后日度基础指标同步
- 当前主用源：`Tushare daily_basic`
- 当前系统服务口径：显式同步当天 `trade_date`

### 4.4 板块同步

- 板块目录同步：东方财富
- 板块成分股同步：东方财富
- 当前板块运行对象只保留：
  - `standard_sectors`
  - `standard_sector_stocks`
  - `job_runs`
  - `data_quality_log`
- 旧 `sector_*` 表已删除，不再参与当前盘后链路

## 5. 数据真值层

### 5.1 realtime_quotes

- 盘中秒级 / 准秒级快照事实层
- 当前只保留 `2026-04-07` 起的数据窗口

### 5.2 kline_minute

- 统一分钟事实层
- 当前只保留 `2026-04-07` 起的数据窗口

### 5.3 kline_daily

- 盘后日线真值层
- 当前历史已恢复，范围为 `2010-01-28` 到最新盘后日线

## 6. 审计与监控

### 6.1 job_runs

- 盘中 `collect_realtime` 每轮写一条
- 盘后 `reconcile_daily` / 板块同步任务也写生命周期记录

### 6.2 data_quality_log

- 记录盘中源错误、软失败、heartbeat、盘后缺口和同步异常

## 7. 操作建议

1. 先看 `job_runs` 判断今天盘中和盘后任务是否真的跑过。
2. 再看 `data_quality_log` 判断是源问题还是本地写入问题。
3. 对日线问题，先确认 `reconcile_daily` 的 `run_date` 和 `processed_count`。
4. 对板块问题，先确认 `sync_eastmoney_sectors` 成功，再看 `sync_eastmoney_sector_stocks`。
