# 板块同步运行

## 1. 东方财富板块目录同步

- 入口：
  - `python collector/sync_eastmoney_sectors.py --host 127.0.0.1 --port 5432 --user wt --password '***' --dbname stock_realtime`
- 职责：
  - 从 `https://quote.eastmoney.com/center/api/sidemenu_new.json` 拉取行业 / 概念板块目录
  - 写入 `public.standard_sectors`
  - 任务生命周期写入 `public.job_runs`
- 失败观测：
  - 目录抓取失败会写 `public.data_quality_log`
  - `issue_type='source_error'`

## 2. 东方财富板块成分股同步

- 入口：
  - `python collector/sync_eastmoney_sector_stocks.py --host 127.0.0.1 --port 5432 --user wt --password '***' --dbname stock_realtime`
- 职责：
  - 读取 `public.standard_sectors` 中 `source='eastmoney'` 且 `sector_code LIKE 'BK%'` 的板块
  - 逐板抓取成员并写入 `public.standard_sector_stocks`
  - 只有通过完整性校验的板块才会执行替换；可疑不完整结果只记日志，不删除旧成员
  - 失败板块写入 `public.data_quality_log`
  - 同步任务写入 `public.job_runs`
- 推荐参数：
  - `--sector-type industry` 或 `--sector-type concept`
  - `--limit N` 限制板块数量做小范围验证
  - `--dry-run` 仅抓取不落库，适合先检查源可用性
  - `--min-coverage-ratio 0.7` 控制相对历史成员数的最低覆盖比例
  - 当前正式策略：`efinance` 作为东方财富口径的新抓取源，按 `50` 个股票一批推进，批次间隔 `1` 秒，支持断点续跑

## 3. 同步顺序

当前板块同步任务从 `20:00` 开始，推荐顺序：

1. 先判定今天是否为交易日；非交易日整条板块链路跳过。
2. 先跑板块目录同步，确保 `public.standard_sectors` 只收敛到当前有效板块。
3. 最后跑板块成分股同步，确保 `public.standard_sector_stocks` 依赖的板块上下文是最新的。
4. 如果成员同步失败，优先检查 `data_quality_log`，不要直接清理历史数据。

## 3.1 当前板块主线表

- 当前板块主线只保留：
  - `public.standard_sectors`
  - `public.standard_sector_stocks`
  - `public.job_runs`
  - `public.data_quality_log`
- 旧表 `public.sector_mapping`、`public.sector_operation_log`、`public.sector_quotes_daily`、`public.sector_sync_log`、`public.sectors` 已删除，不再作为运行对象。

## 4. 常用排障 SQL

- `psql -h 127.0.0.1 -p 5432 -U wt -d stock_realtime -f sql/verify_sector_sync.sql`
- `SELECT job_name, status, processed_count, started_at, finished_at FROM public.job_runs WHERE job_name LIKE 'sync_eastmoney_%' ORDER BY started_at DESC LIMIT 20;`
- `SELECT data_domain, issue_type, issue_level, created_at, left(issue_message, 180) FROM public.data_quality_log WHERE data_domain IN ('sector_sync', 'sector_members') ORDER BY id DESC LIMIT 20;`
- `SELECT sector_type, count(*) FROM public.standard_sectors GROUP BY 1 ORDER BY 1;`
- `SELECT count(*) FROM public.standard_sector_stocks;`

## 5. 运行注意

- 目录同步和成员同步都不是 collector 的实时主链路，不应影响 `realtime_quotes -> kline_minute -> kline_daily`。
- 遇到 Eastmoney 源临时断连时，优先靠退避和重试，不要在 collector 中引入策略级回退逻辑。
- 成员同步目前只覆盖 `source='eastmoney'` 的板块，Tushare 历史板块暂不纳入本轮 collector 任务。
